# Coach Gopi website

The live website for Coach Gopi, a running coach, nutrition and diet coach, corporate wellness and running event consultant in Ahmedabad: https://www.coach-gopi.com/

This repository holds only the files that are published on the website. It is hosted as a static site on Render and redeploys when `main` changes.

## What is here
- Pages: `index.html` and the folders `about-coach-gopi/`, `running-coach-ahmedabad/`, `nutrition-diet-coach-ahmedabad/`, `corporate-wellness-ahmedabad/`, `running-event-management-consultant-ahmedabad/`, `contact/`, `privacy-policy/` and `terms-and-disclaimer/`.
- Share cards (not in the menu, not indexed): `card.html` (Gopi's intro card) and `refer.html` (the card clients and local businesses use to recommend him).
- `assets/`: stylesheet, form script, photos and the share preview image.
- Search files: `sitemap.xml`, `robots.txt`, `llms.txt`. Icons: `favicon.*`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest`.
- `design-system/`: the design tokens, brand book and component notes (reference only).

## How the pages are made
The pages are generated by build scripts that are kept outside this repository, so they are not published on the website: the page builder, the share-card builder, the preview-image builder and the automated tests. The scripts and their README are in the `gopi-site-dev-files` archive, and every earlier version is in this repository's git history.

Facts that matter when changing the site:
- The live address is `https://www.coach-gopi.com/`, used in canonical links, share previews, the sitemap and the cards.
- Enquiry forms email Gopi through FormSubmit, with a WhatsApp fallback.
- No analytics or advertising cookies are used. If analytics is added, update the Privacy Policy.
