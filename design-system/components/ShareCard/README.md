The shareable intro or refer card, designed at 540px wide and exported at 2x for a 1080px picture.

It is generated by `tools/build-card.mjs` from `card.config.json`: do not draw one by hand. Contents, top to bottom: an ink header bar (the name and either "Referred by <name>" or the tagline), a round photo, the name in `card-name`, the tagline, one credential chip, one offer line, an optional "Recommended by" badge, then the `accent` WhatsApp tile showing the link and a QR code for the same link.

- Provide the name, tagline, a square photo, one offer line, one credential and the live link (`https://www.coach-gopi.com/`, plus `?ref=<slug>` on a refer card).
- The badge appears only with real counts (`recommended` is `{ "clients": N, "businesses": N }`); never invent them.
- The QR is black on white in a white tile so it scans in either theme.
- The preview shows initials where the real photo goes.
