A small uppercase tag for a credential or a plan type.

Use `gd-chip` (river on river-tint) for credentials and plan labels such as "UESCA certified" and "Free plan". Use `gd-chip gd-chip--accent` only for the single main programme.

- Provide the text, a few words at most, in the `tag` style.
- A share card carries exactly one credential chip.
- The accent chip is 3.8:1 in light: keep it to the 12px uppercase tag and never use it for running text.
