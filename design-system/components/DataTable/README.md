A bordered table for paces, prices and any list of facts that line up in columns.

Wrap a `gd-table` in `gd-table-wrap` so it scrolls inside its own box on phones. Header cells are mono uppercase in muted on `bg`. Numeric cells take the class `n` so digits are mono and tabular and never wrap.

- Provide a header row and rows of short cells. Currency is rupees with a thousands comma: "₹2,750".
- Put the row label in the first column; it is set bold.
- Do not use it for layout.
