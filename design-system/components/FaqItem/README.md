An expandable question and answer, separated from the next by a hairline.

Use native `<details>` and `<summary>` inside `gd-faq`. The question is the summary (19px, bold) with a plus that turns into a minus when open; the answer is muted body text.

- Open the first item by default. Questions are written as the runner would ask them.
- Answers are one to three sentences and must match the record (prices, times, commitment).
